# INST377-Final-Project
Currency Conversion

Foreigners, whether if they're students or travelers, are always on the go. This means that ehy would need a quick and reliable currency conversion while being in an unfamiliar environment. The goal of this project is to provide a web-app that allows users to get real-time exchange rates, see the conversions, and monitor or compare trends between one or more currencies. Due to the availability of the app, it is widely available for all devices, meaning there aren't any compatibility issues. 



# Developer Manuel:
The app allows users to view live exchange rates, convert between two different currencies, store conversion history, and deploying through vercel. 

The app mostly involves the usage of HTML, CSS, and JSON. 

Before proceeding, user must download npm. Supabase will also be used, which is to store and manage currency conversion records. This allows users to work through what they have to fix any bugs. 

After installing npm, there are other packages to install, including: express, body-parser, dotenv, supabase/supabase-js, and nodemon. 

After getting in and checking that the environmental variables are set up correctly, people can go ahead and start using it. Although the project seems positive, there are some limitations. One of which is the vulnerability of any hacks.
